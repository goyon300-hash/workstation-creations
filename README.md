## Where to record things

- **What exists:** this index and each project's README.
- **What changed:** Git commits and the project's CHANGELOG.
- **What is planned or broken:** issues in the relevant repository.
- **How to install and test:** each project's installation/development instructions.
- **What changed on a specific PC:** the private `agent-change-log` installation, not a public source repository.

Edit canonical project source, run its tests, inspect `git diff`, and commit a focused change. Installing a local tool does not automatically commit future changes or prove a remote backup exists.

## Scope and privacy

These repositories contain reviewed source and synthetic examples, not a full workstation backup. Credentials, actual model inventories, notification destinations, personal startup commands, conversations, runtime databases, agent state, machine-specific environment files and migration backups must stay private.

The obsolete Herdr TUI agent-state extension is not part of the published Pi package. Imported skills and unmodified third-party installations are not presented as original creations. Historical projects and creative demonstrations are outside this publication pass.

## Licensing

Existing upstream projects keep their original licenses and notices. No blanket license is imposed across these independent repositories. Where an original project's repository has no license file, public visibility alone does not grant an open-source license.
